# 🎯 CHECKLIST: COMO IDENTIFICAR PHISHING

## ANTES DE INTERAGIR COM O EMAIL

### ✅ Verificação do Remetente
- [ ] O endereço de e-mail é exatamente igual ao oficial?
- [ ] O domínio após o @ é legítimo? (sem erros de digitação)
- [ ] Você esperava receber este e-mail?
- [ ] A empresa ou pessoa realmente costuma te mandar mensagens assim?

### ⚠️ Sinais de Alerta no Conteúdo
- [ ] O e-mail cria URGÊNCIA (“responda agora”, “sua conta será bloqueada”)?
- [ ] Oferece algo BOM DEMAIS para ser verdade?
- [ ] Pede dados pessoais ou financeiros?
- [ ] Tem ERROS de português ou tradução estranha?
- [ ] Usa saudações genéricas (“Prezado cliente”)?
- [ ] A mensagem tem TONS de letras maiúsculas ou pontos de exclamação?

### 🔗 Análise de Links
- [ ] Você passou o mouse sobre o link e viu se o endereço confere?
- [ ] O link usa um encurtador (bit.ly, tinyurl)?
- [ ] O domínio tem letras trocadas (paypa1.com, g00gle.com)?
- [ ] Há redirecionamentos estranhos?
