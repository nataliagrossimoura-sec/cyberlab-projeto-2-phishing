# 🎯 CHECKLIST: Como Identificar Phishing

## ANTES DE INTERAGIR COM O EMAIL

### ✅ Verificação do Remetente
- [ ] O endereço de email é exatamente igual ao oficial?
- [ ] O domínio após @ é legítimo? (sem erros de digitação)
- [ ] Você esperava receber este email?
- [ ] A pessoa/empresa costuma entrar em contato assim?

### ✅ Sinais de Alerta no Conteúdo
- [ ] Há senso de URGÊNCIA artificial?
- [ ] Há AMEAÇAS (bloqueio, multa, processo)?
- [ ] Pede informações SENSÍVEIS (senha, cartão, CPF)?
- [ ] Oferece algo BOM DEMAIS para ser verdade?
- [ ] Há ERROS de português ou tradução estranha?
- [ ] A saudação é GENÉRICA ("Prezado cliente")?

### ✅ Análise de Links
- [ ] Passe o mouse sobre links SEM CLICAR - o destino confere?
- [ ] O link usa ENCURTADOR (bit.ly, tinyurl)?
- [ ] O domínio tem CARACTERES estranhos (paypa1, g00gle)?
- [ ] Há MÚLTIPLOS redirecionamentos?

### ✅ Anexos
- [ ] Você ESPERAVA receber um anexo desta pessoa?
- [ ] O arquivo tem extensão EXECUTÁVEL (.exe, .scr, .bat)?
- [ ] É um documento com macros (.docm, .xlsm)?
- [ ] O nome do arquivo é genérico ou suspeito?

## SE RESPONDEU "SIM" A QUALQUER ITEM ⚠️
🚨 **NÃO CLIQUE, NÃO RESPONDA, NÃO BAIXE**
Ações a tomar:
1. Reportar ao setor de TI/Segurança
2. Marcar como spam/phishing
3. Deletar o email
4. Se já clicou: trocar senhas imediatamente e escalar ao suporte
